Welcome to Scrippy

Scrippy converts images from one format to another. It works from the Quick Actions menu in Finder.

What Scrippy does

  • Converts to many formats. Choose JPEG, PNG, HEIC, TIFF, PDF, and more. The full list depends on your version of macOS. Scrippy describes what each format is good for.
  • Converts many images at once. Select several images or a whole folder.
  • Keeps your originals. Each converted image is a new file saved next to the original. Scrippy never replaces a file.
  • Offers optional shortcuts. One-step actions convert straight to JPEG, PNG, or HEIC. You choose which ones you want on the Installation Type page.

Before you install

  • Scrippy needs macOS 11 or later.
  • It installs only for your account. No administrator password is needed.
  • It works offline. Scrippy uses the image tools built into macOS and never connects to the internet.
