# Assets

Every icon file here is generated by `Scripts/make_icons.py` from one
arrangement, so every size and variant shows the same design. Edit the script,
not the output, then run it from the repository root:

```bash
python3 Scripts/make_icons.py
```

The SVG files hold shapes and colors only, with no title, description,
comments, or editor data. The PNG files hold image data only, with no text,
time, or color profile chunks.

## Files

| File | Purpose |
| --- | --- |
| `AppIcon.svg` | The icon on its rounded tile, the source for every PNG |
| `Icon-Transparent.svg` | The same artwork without the tile, for pages. Adapts to light and dark appearance |
| `Icon-Tile.svg` | The same artwork on a 48 unit dark tile with a corner radius of 7, matching the other projects |
| `Icon-Mono.svg` | The same artwork in one color through `currentColor`, for places that tint the mark |
| `png/AppIcon-N.png` | The app icon at 16, 24, 32, 48, 64, 128, 256, 512, and 1024 pixels |
| `png/Icon-Tile-N.png` | The tile at 16, 24, 32, and 48 pixels |
| `../package/resources/background.png` | The icon without its tile, for the lower left corner of the Installer window in light appearance |
| `../package/resources/background-dark.png` | The same for dark appearance |
| `screenshots/` | Screenshots for the README, taken by hand and cleaned with `Scripts/clean_screenshots.py` |

The installer background is rendered at twice its size and marked as 144 dots
per inch, so it stays sharp on a Retina display. That resolution mark is the
one chunk it carries beyond the image data.

## What the icon shows

One image file sits at the center. Lines run from it to smaller image files
spread around it, each with a label in a different color. One picture going
out to many formats is the whole job of Scrippy, and the varied labels
stand for formats without naming any, so the icon never suggests a fixed pair
such as JPEG to PNG.

## How the copies are placed

The copies are not placed by hand. They follow the arrangement a sunflower
uses for its seeds.

- **Angle.** Each copy sits one golden angle, about 137.5 degrees, past the
  one before it. That angle is an irrational fraction of a full turn, so no
  copy ever lands directly in line with an earlier one, and the spread looks
  uneven without any copy crowding another.
- **Distance.** Copies sit on equal-area rings. The radius of copy *n* of *N*
  is the square root of `inner² + (outer² − inner²) × (n − ½) / N`, which
  gives every copy the same share of the space around the center.
- **Size.** Each copy grows in proportion to its distance from the center, as
  the outer florets of a sunflower do.

The starting rotation, the inner and outer ring radii, and the copy size were
found by searching for the arrangement that keeps every copy inside the rounded
tile with the widest gap between neighbors. The size of the center file was set
by eye. The golden angle itself is never adjusted.

## Color

| Role | Value |
| --- | --- |
| Tile | `#11161C` |
| Paper | `#F4F1EA`, fold `#D3CCBE` |
| Spokes | `#5A6675` |
| Center label | Coral, `#D9604C` |
| Copy labels, in placement order | `#2E9C82`, `#E39B2D`, `#3F7FD1`, `#C9506E`, `#7FA83A`, `#8A4FA8`, `#2BA0B5`, `#D4B62C`, `#B5489E` |

The labels are given out in the order the spiral lays the copies down. As
placed, each copy differs in hue from its two nearest neighbors by at least 32
degrees, so no two copies side by side look alike. All ten label colors are
different.

Every shape is a flat fill. There are no gradients, shadows, or highlights,
which keeps the files small and leaves macOS free to add its own treatment.

## Small sizes

Every size uses the full artwork. At 32 pixels and below the nine copies read
as a ring of small marks around the center file rather than as separate
pictures, which keeps the outline of the icon the same at every size.
