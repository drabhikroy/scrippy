Scrippy converts images to any format your Mac can write without leaving
Finder. Select one image, several images, or a folder. Right-click and choose
**Convert with Scrippy**. The new copies are saved next to the originals, and
the originals never change.

## What it does

- Lists every format SIPS can write on your Mac, including JPEG, PNG, HEIC,
  AVIF, TIFF, JPEG 2000, GIF, and PDF
- Explains each format in plain terms, such as whether it keeps transparency
  and how widely it opens
- Offers six image detail settings for JPEG, HEIC, AVIF, and JPEG 2000
- Estimates the size of the result before you convert
- Converts batches, and every image directly inside a folder, in one pass
- Adds one-step Convert to JPEG, PNG, and HEIC actions that skip the window
  and are optional at install
- Shows progress for long batches, with a Stop button
- Includes a small app with built in help, an example image to practice on,
  and an uninstaller
- Runs entirely on your Mac, with no account, no server, and no network
  connections

## Install

Download `Scrippy-1.0.0.pkg` below and open it. It installs to your own
account and asks for no administrator password. On the Installation Type page
you can choose which one-step actions to add. Afterward, open Scrippy from the
Applications folder in your home folder to get started.

To remove Scrippy later, open `Uninstall-Scrippy-1.0.0.pkg`, also below.

## Requirements

macOS 11 or later, Apple silicon or Intel.

## Verify the download

`SHA256SUMS.txt` is published with this release. With it in the same folder as
the packages:

```bash
shasum -a 256 -c SHA256SUMS.txt
```
